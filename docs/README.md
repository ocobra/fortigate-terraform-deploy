# FortiGate Terraform Analysis System Documentation

This directory contains comprehensive documentation for the FortiGate Terraform Analysis System.

## Documentation Structure

- `architecture.md` - System architecture and design decisions
- `api.md` - API reference and programmatic usage
- `cli.md` - Command-line interface documentation
- `configuration.md` - Configuration options and examples
- `development.md` - Development setup and contribution guidelines
- `examples/` - Usage examples and sample configurations
- `testing.md` - Testing strategy and guidelines

## Quick Start

1. **Installation**: See the main README.md for installation instructions
2. **Basic Usage**: Check `cli.md` for command-line usage examples
3. **Configuration**: Review `configuration.md` for customization options
